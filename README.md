# InteractiveResponseSystem
即時反饋系統 (IRS) - 基於形成性評估的教學互動系統

📌 專案介紹

本系統是一款專為課堂互動與形成性評估設計的即時反饋系統（Immediate Response System, IRS）。透過即時作答、數據分析與出缺席紀錄，協助教師掌握學生的學習情況，提升教學成效。

教師可以建立即時互動活動，學生透過行動裝置參與作答，系統將即時回饋結果，並提供詳細的統計分析與視覺化圖表，讓教師能夠根據數據調整教學策略。

🎯 主要功能

✔ 即時互動作答：支援單選/多選題型，提供作答計時功能。/n
✔ 作答數據分析：即時計算學生作答情況，生成圖表報告。
✔ 出缺席紀錄：參與互動即計為當日出席，教師可手動調整。
✔ 課程討論區：學生與教師可發表問題與留言討論。
✔ Firebase 雲端同步：支援即時資料更新與身份驗證。
