# InteractiveResponseSystem
即時反饋系統 (IRS) - 基於形成性評估的教學互動系統

📝 專案介紹

本系統是一款專為課堂互動設計的 即時反饋系統（Immediate Response System, IRS），透過即時作答、數據分析、出缺席管理等功能，幫助教師快速掌握學生的學習狀況，提升教學成效。  

💡 主要理念：形成性評估（Formative Assessment）  

本系統的核心設計理念來自形成性評估，透過持續性的學習回饋，讓教師能夠根據即時數據調整教學策略，進而提升學生的學習效果。  

📌 主要特色

✅ 即時互動作答：  
    •    教師可發佈即時互動活動，學生透過行動裝置參與作答。  
    •    支援 單選、多選題型，並可設定每題的答題時間。  
    •    學生提交答案後，系統立即計算正確率，並提供即時統計結果。  

✅ 作答數據分析：  
    •    提供 即時統計圖表，幫助教師分析學生的作答情況。  
    •    透過 Bar Chart 圖表化顯示 各題正確率，協助教師調整教學內容。  
    •    學生可查看自己的歷史作答紀錄，幫助自我學習與檢討。  

✅ 出缺席管理：  
    •    將學生參與即時互動活動與出席紀錄綁定，確保出席狀況準確無誤。  
    •    若學生當日至少參與一次互動活動，則視為當日出席。  
    •    教師可手動調整學生的出席狀況，確保完整記錄。  

✅ 課程討論區：  
    •    提供課程內討論區，讓學生與教師能夠進行即時交流。  
    •    學生與教師可匿名發表問題或回應討論，促進課堂內外互動。  

✅ 雲端同步與即時更新：  
    •    Firebase Realtime Database 支援即時數據同步，確保教師與學生的互動即時有效。  
    •    Firebase Authentication 負責身份驗證，確保教師與學生擁有正確的權限。  


🎯 使用場景

📌 大學或高中課堂 - 促進課堂互動，提升學習參與度。  
📌 遠端教學 - 透過即時反饋機制，提高線上學習的互動性。  
📌 企業內訓 - 讓企業講師能夠透過測驗即時掌握學員學習狀況。
